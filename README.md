# Delta Lab — Luau Companion

A lightweight, mobile-first scripting companion for learning Luau and developing your own Roblox Studio experiences.

## Current milestone: v0.1.0
- Responsive dark editor interface
- Local script library (browser storage)
- Copy script to clipboard
- Basic formatting checks (does not execute code)
- Console for local diagnostics
- Roblox Studio workflow guidance
- Installable PWA shell with offline caching

## Run
Enable GitHub Pages for this repository and open its HTTPS site. On Android Chrome, use **Add to Home screen** to install the PWA.

## Privacy
Saved scripts are stored in browser localStorage on the current device. Clearing browser data can erase them. Export/backup is planned.

## Scope
This project does not inject into, modify, or execute code inside the Roblox client. Use Roblox Studio to test scripts in experiences you own or are authorised to develop.
